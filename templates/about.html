About Easy Insurance

Easy Insurance is a machine learning based insurance prediction system designed to estimate insurance charges based on personal, financial and lifestyle information.

The system uses a trained Machine Learning model to analyze factors such as age, BMI, dependents, smoking habits, salary, expenditure, occupation, chronic diseases, alcohol consumption and marital status.

The application provides a simple web interface where users can create an account, securely log in, enter their information and receive an estimated insurance charge.
